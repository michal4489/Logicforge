# Pomoc i zgłoszenia

Problemy i propozycje funkcji zbieramy w [Issues](https://github.com/michal4489/Logicforge/issues/new/choose).

Sprawdź [FAQ](docs/FAQ.md) i istniejące zgłoszenia. Podaj wersję LogicForge, wersję Windows, kroki, oczekiwany efekt oraz faktyczne zachowanie. Zrzut lub minimalny projekt `.lfg` bardzo pomaga.

Issues są publiczne. Nie dodawaj haseł, tokenów, prywatnych danych ani poufnych projektów. Usuń prywatne informacje ze zrzutów i logów.

Poprawki dokumentacji można proponować przez pull request. Kod aplikacji jest rozwijany prywatnie; to repozytorium nie zawiera procesu budowania aplikacji.
