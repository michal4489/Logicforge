# Przykładowe układy

Otwórz plik na GitHubie, kliknij **Download raw file**, zapisz jako `.lfg` i wybierz **Otwórz projekt** w LogicForge. Przykłady są też dołączone do instalatora w **☰ → Przykładowe układy**.

| Plik | Zawartość |
| --- | --- |
| [polsumator.lfg](polsumator.lfg) | Dwa wejścia, suma XOR i przeniesienie AND. |
| [ram-8bit.lfg](ram-8bit.lfg) | Pamięć 8 bit z zapisem i odczytem. |
| [kalkulator-ram-8bit.lfg](kalkulator-ram-8bit.lfg) | Klawiatura, IC CALC-8, RAM i dwa wyświetlacze. |
| [zegar-przerzutnik.lfg](zegar-przerzutnik.lfg) | Zegar i przerzutnik. |

Zalecana wersja: **0.14.0 lub nowsza**, szczególnie dla kalkulatora korzystającego z poprawionej obsługi kliknięć.
