# Pytania i odpowiedzi

**Gdzie jest instalator?**

Opublikowane instalatory będą w [Releases](https://github.com/michal4489/Logicforge/releases), w Assets. Jeśli nie ma wydania, instalator nie został jeszcze publicznie udostępniony. Download ZIP pobiera repozytorium, a nie aplikację.

**Czy muszę instalować .NET?**

Instalator Windows x64 zawiera wymagane środowisko.

**Czy aplikacja działa offline?**

Tak. Edycja, symulacja, tutorial i wbudowane przykłady działają lokalnie.

**Czy są automatyczne aktualizacje?**

Wersja 0.14.0 nie ma jeszcze opublikowanego mechanizmu automatycznych aktualizacji. Nowe wersje sprawdzaj w Releases. Powiadomienia GitHub można włączyć przez Watch → Custom → Releases.

**Czy kliknięcia wymagają pauzy?**

W 0.14.0 przyciski działają również podczas symulacji. Pauza zatrzymuje upływ czasu; Play pozwala pracować zegarom. Przycisk chwilowy puść po naciśnięciu.

**Jak otworzyć przykład?**

Pobierz surowy plik `.lfg`, a potem wybierz Otwórz projekt. Nie zapisuj strony HTML GitHuba jako projektu.

**Czy kod jest open source?**

Nie. Źródła aplikacji są prywatne. Zobacz [informacje o prawach](../COPYRIGHT.txt).

**Czy działa na Linux, macOS lub Windows ARM?**

Obecny pakiet jest dla Windows x64. Nie udostępniono tu wydań dla pozostałych platform.
